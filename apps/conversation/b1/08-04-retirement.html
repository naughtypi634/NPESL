The Conversation

我叫阿瑟，六十二岁。重音自我介绍，Arthur 是新信息焦点。
在我们国家，国家养老金从六十五岁开始发放，大约是平均工资的百分之六十。重音说明养老金起始年龄与替代率，pension 与 percent 是核心。
我这一代很多人没有为未来存钱，因为他们相信国家会照顾他们。重音对比那代人没存钱而指望国家，save 与 state 是焦点。
有些人现在才发现，国家并不会。重音如今发现国家靠不住，now 与 not 是焦点。
我妻子去年退休，她从没这么忙过。重音妻子退休后反而更忙，retired 与 busier 是对比焦点。
她每周照看两次孙辈，画画，还和她姐姐一起旅行。重音列举妻子的三种活动，grandchildren/paints/travels 是重点。
我也可以退休，但我喜欢我的工作，想多干一段时间，因为我晚点退休养老金会更高。重音对比能退休却想继续工作，job/longer/higher 是焦点。
我也想保留工作带来的医疗保险。重音保留工作附带的医疗，care 是焦点，health 是限定。
没人愿意问的问题是：谁来付钱？重音真正的问题是钱由谁出，pay 是焦点，who 是疑问核心。
我们的人口正在老龄化，每个退休者对应的年轻劳动者越来越少。重音人口变老与年轻劳动者减少的对比，older/fewer 是焦点。
我女儿三十五岁，她在缴一份私人养老计划，因为她对国家不抱太大期望。重音女儿缴私人计划、不指望国家，plan 与 state 是焦点。
如果要给三十岁的人建议，我会说：现在就开始，哪怕金额很小。重音给三十岁的人的建议是现在开始，start 与 now 是焦点。
不是为了变富。重音否定目标是变富，rich 是焦点。
而是为了到时候有能力停下来。重音真正目标是负担得起停止工作，afford 与 stop 是焦点。

Comprehension Questions

  1. 在亚瑟的国家，国家养老金从多少岁开始发放？重音问养老金起始年龄，age 是焦点。
  2. 为什么他那一代人里很多人都不存钱？重音问那代人为何不存钱，Why 与 save 是焦点。
  3. 他妻子现在做什么工作？重音问妻子现在做什么，What 是焦点。
  4. 亚瑟为什么想继续工作？重音问 Arthur 为何想继续工作，Why 与 working 是焦点。
  5. 他对30岁的人有什么建议？重音问给三十岁的人什么建议，advice 是焦点。

Conversation Starters

  1. 在你们国家，人们多大年纪退休？重音问贵国几岁退休，age 是焦点。
  2. 国家发的养老金够维持生活吗？重音问国家养老金是否够生活，enough 是焦点。
  3. 你会为将来存钱吗？重音问是否为未来存钱，save 是焦点。
  4. 你愿意65岁以后还继续工作吗？重音问是否愿意 65 岁后继续工作，work 是焦点。
  5. 在你们国家，退休的人一般怎么打发时间？重音问退休者如何打发时间，time 是焦点。
  6. 年轻人应该多交养老金吗？重音问年轻人是否该多缴养老金，more 是焦点。
  7. 你指望老了以后国家来照顾你吗？重音问是否指望国家养老，state 与 old 是焦点。
  8. 退休以后你打算怎么安排空闲时间？重音问退休后如何安排空闲时间，What 与 time 是焦点。
  9. 人口越来越老龄化是个问题吗？重音问人口变老是否是问题，problem 与 older 是焦点。
  10. 你觉得要有多少钱才能过得舒服？重音问需要多少钱才觉得舒适，much 与 comfortable 是焦点。
