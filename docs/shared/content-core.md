# 共享内容核 · content-core

本文件是两个英语教学库共用的内容底线。它只定义内容标准，不定义构建、检查、部署、目录或页面形状；副本只读，不参与任何构建。冲突时以各库自己的根 `AGENTS.md` 为准；本文件出现构建/页数/部署条款即视为越界。

## 1. 受众

面向 2026 年中国成年英语学习者，默认 A1–A2。英语可以简单，话题不能幼稚；例句、讨论题、练习场景贴近当代中国成年人生活（外卖、地铁通勤、加班、面试、租房、微信等），不用过时或陌生场景。

## 2. 美式英语

拼写、词汇、语法、日期数字格式一律美式。示例：`color` / `center` / `favorite` / `realize` / `traveling` / `canceled`；`apartment` / `elevator` / `line` / `trash` / `sidewalk` / `parking lot` / `crosswalk` / `subway` / `vacation` / `truck` / `cell phone` / `movie theater` / `cookies` / `fries` / `math` / `soccer` / `gas` / `package` / `fall` / `pharmacy` / `zip code` / `takeout` / `store`。日期 `September 12, 2026`，数字 `1,500`。公制单位和中国地铁官方英文名保留。完整替换清单与检查器在各库自己的 `standards/` 与 `check_bre.py`，不在本文件复制。

## 3. 具体画面

每条例句必须包含具体场景、人物和动作，让读者能立刻在脑中成像并代入；禁止干巴巴的通用例句。

## 4. 当代习语

只选 2020 年代英语口语中真实高频的习语/俚语；避免教科书式、老套、过时的表达（`over the moon`、`raining cats and dogs` 之类）。拿不准先查证。

## 5. 学习者可见内容不做进度与统计

不显示已学/完成标记、打卡勾选、进度徽章；不显示任何计数；不写「N 个主题 · N 条 · 点词条就出声」这类统计/说明型 meta 文案。功能性 UI 标签、中文开关、重音注不在此列。
